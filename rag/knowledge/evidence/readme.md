# Evidence

本目录把不同来源返回的文本整理成可供生成和引用使用的统一证据。

应该放入：

- 证据标准化、去重和合并；
- 相关性、可信度、时效性和覆盖度评分；
- 本地知识库、SQL、Web 和外部工具证据的统一表示；
- 数字、日期、定义和来源冲突检测；
- 证据充分性判断；
- 无法回答、需要 Web Search 或需要人工确认的判断结果。

每条 Evidence 必须保留从标准化/合并文本回到原始 RawSource、Document Version、叶子 Chunk 和原文范围的映射。去重或相邻 Chunk 合并只能改变展示文本，不能丢失 `content_hash`、`leaf_chunk_ids` 或 `source_spans`。

本目录不负责直接生成最终答案，也不把未经验证的外部文本当作系统指令。
